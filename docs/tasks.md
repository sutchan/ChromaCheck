## 2. P0 任务（安全与合规）

### O-01 Next.js 安全补丁升级与 `npm audit` 收敛

- **已完成部分**：`package.json` / `package-lock.json` 的 `next` 与 `eslint-config-next` 已升至 `14.2.35`；node_modules 重装后类型声明完整；`tsc` / ESLint / Vitest（111 例）/ 覆盖率门禁 / OpenAPI / 文档一致性校验全绿。
- **阻塞点**：`npm audit --omit=dev --audit-level=critical` 仍报告 critical —— 审计库判定 **所有 Next 14.x**（含 14.2.35）受多项未修复漏洞影响，官方 `npm audit fix --force` 给出 `next@16.4.6`（跨 major，破坏性变更）。
- **待决策**：① 保持 Next 14 并接受审计告警（当前选择，项目为纯前端静态站点，多数漏洞涉及 Image Optimizer / Server Actions / rewrites 等未使用能力）；② 迁移 Next 16 并做完整回归。需项目负责人确认后执行。
- **验收标准**：`npm audit --omit=dev --audit-level=critical` 无 critical，或书面接受风险并记录例外。
- **责任人 / 计划**：待指派（前端维护者）／2026-12-05。
