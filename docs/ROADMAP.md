## 2. v1.0 — MVP（历史规划阶段，已完成）

### 2.1 目标

完成核心色觉检测闭环，验证产品可行性。

### 2.2 功能范围

**包含**：
- 首页 / 检测前指引
- 石原氏数字图测试（快速 10 题 / 标准 38 题）
- 判读算法（总体结论、程度、置信度；类型为退化输出）
- 结果展示（维度分析 + 解读 + 建议）
- 历史记录（本地存储）
- 响应式 + 深色模式

**不包含**（推迟到后续版本）：
- 路径追踪测试
- 色相排列测试
- 用户账号
- 报告导出（PNG/PDF）

### 2.3 完成标准

- [ ] 完整检测流程可运行
- [ ] 判读算法测试覆盖 ≥ 95%
- [ ] 部署上线
- [ ] 隐私合规检查通过

### 2.4 里程碑

| 阶段 | 内容 | 工期 |
|------|------|------|
| M1 | 项目初始化、首页、指引 | 1 周 |
| M2 | 石原氏测试、判读引擎 | 2 周 |
| M3 | 结果展示、历史记录 | 1 周 |
| M4 | 测试、上线 | 1.5 周 |

## 11. 优化建议与未来展望（v1.17.5 系统评估）

> 本节来自对代码实现、架构设计、性能与用户体验的同步评估。每条含问题背景、实施方案、预期效果与优先级；执行状态统一登记在 [tasks.md](./tasks.md)。责任人与计划完成时间为建议值，待项目负责人确认。

### O-01 升级 Next.js 至安全补丁版本

- **背景**：npm 提示 `next@14.2.15` 存在 2025-12-11 披露的安全漏洞；依赖已升至 `14.2.35`，本机 lint / type-check / test / coverage / OpenAPI / 文档校验全绿，但 `npm audit --omit=dev --audit-level=critical` 仍报告 1 个 critical（审计库判定全部 Next 14.x 受影响）。当前选择保持 Next 14 并接受审计告警，跨 major 至 Next 16 需业务决策（见 [tasks.md](./tasks.md) O-01）。
- **方案**：维持 Next.js 14 同 minor 补丁版本 `14.2.35`；若决定跨 major，则迁移至 Next 16 并做完整回归。无论选择哪条路径，均需完成 lint / type-check / test / coverage / build / E2E 与 Preview 冒烟。
- **预期效果**：消除已知 CVE，`npm audit` 关键项归零；构建与运行行为保持不变。
- **优先级**：**P0**（安全），建议 2026-12-05 前完成。

### O-02 修复语言恢复时 `html lang` 未同步

- **背景**：`components/layout/LangProvider.tsx` 挂载后从 `cc.lang.v1` 恢复语言时未改写 `<html lang>`，只有 `setLang()` 才更新；`app/layout.tsx` 初始硬编码 `zh-CN`，繁中 / 英文用户首屏语义标记错误（WCAG 3.1.1）。
- **方案**：在挂载恢复语言的 effect 中调用 `setLang()` 的公共副作用（或抽 `applyHtmlLang(lang)` 纯函数），并补一条断言 `document.documentElement.lang` 的组件测试。
- **预期效果**：三语环境 `html lang` 正确率 100%（验收：`zh-CN` / `zh-TW` / `en` 三种取值均正确）。
- **优先级**：**P0**（无障碍 / 合规），建议 2026-12-05 前完成。

### O-03 补齐覆盖率门禁与关键路径 E2E

- **背景**：16 文件 111 例覆盖判读与工具逻辑，UI 主链路此前无自动回归。
- **方案（已落地）**：① `vitest.config.ts` 配置 V8 覆盖率与阈值，CI 已执行 `npm run test:coverage`（实测 88.96% lines / 84.3% branches / 87.64% functions）；② Playwright 配置、依赖、脚本与 CI 已接入，`e2e/main-flow.spec.ts` 覆盖首页 → 指引 → 石原氏快速 → 结果。剩余验收为 CI 连续三次稳定通过（O-03）。
- **预期效果**：覆盖率可量化并纳入门禁；核心链路回归从人工 15 分钟降至自动 ~2 分钟。
- **优先级**：**P1**（质量），建议 2026-12-19 前完成。

### O-04 收敛弃用依赖与 npm 环境告警

- **背景**：`rimraf@3`、`inflight`、`glob@7|10`、`eslint@8` 等传递依赖已弃用；部署平台设置 `npm_config_cache_dir` 触发 npm 11 告警。
- **方案**：随 O-01 升级 ESLint 9 / 新版工具链；`package.json` 已通过 `allowScripts` 批准 esbuild；在部署平台将变量名改为 `NPM_CONFIG_CACHE`。
- **预期效果**：安装告警从 8 类降至 0；减少未来 major 升级阻断风险。
- **优先级**：**P3**（可维护性，见 [tasks.md](./tasks.md) O-04），建议 2027-01-15 前完成。

### O-05 补齐内容型文案的繁体版本

- **背景**：`lib/learn-data.ts`、`lib/privacy-data.ts`、儿童图形标签、信号灯题库、`lib/fun.ts` 的 `LocalizedText` 仅简英双语，繁体环境回退简体（见 FEATURES §8）；违反三语「词条齐全」目标。
- **方案**：使用 `opencc-js` 的 `cn→twp` 转换生成 `zh-TW` 字段，人工校对台湾用语（設定 / 搜尋 / 檔案），保持 SSR metadata 恒简中不变。
- **预期效果**：内容型文案三语覆盖率由界面 100% / 内容 0% 提升至整体 100%。
- **优先级**：**P2**（国际化一致性），建议 2027-01-15 前完成。

### O-06 提供官方 Dockerfile 与 Compose 模板

- **背景**：README / DEPLOYMENT 曾要求用户自建 `Dockerfile`，多环境复现成本高。
- **方案**：新增多阶段 `Dockerfile`（`node:22-alpine` + `npm ci` + `next build` + standalone 运行）与 `docker-compose.yml`，纳入 CI 构建冒烟。**当前进展**：模板已提供，锁文件已同步；`npm ci` 镜像构建与 CI 冒烟仍待验证（见 [tasks.md](./tasks.md) O-06）。
- **预期效果**：自托管部署步骤由 6 步降至 2 步；镜像构建可复现。
- **优先级**：**P2**（部署体验），建议 2027-01-15 前完成。

### O-07 结果容量提示与归档

- **背景**：结果上限 30 条，超出会覆盖最早记录；用户此前无感知。
- **方案**：在历史页显示「N/30 条」容量指示，达到上限时提示导出 JSON 归档；存储写入失败用非阻断提示告知。**当前进展**：`RESULT_LIMIT` / `consumeWriteFailure()`、三语容量与失败提示、历史页容量条均已落地，待界面验收（见 [tasks.md](./tasks.md) O-07）。
- **预期效果**：数据丢失投诉风险下降；用户备份率可通过导出按钮点击事件观测（不采集健康数据）。
- **优先级**：**P2**（用户体验），建议 2027-01-15 前完成。

### O-08 环境变量示例与文档同步

- **背景**：`app/layout.tsx` 实际读取 `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` 与 `NEXT_PUBLIC_BING_SITE_VERIFICATION`；两变量已补入 `.env.example` 与 DEPLOYMENT §5。
- **方案**：在 `.env.example` 增加两项注释行（已完成）；将「环境变量校验」纳入 CI 静态检查，避免代码读取与示例脱节（未完成）。当前进展见 [tasks.md](./tasks.md) O-08。
- **预期效果**：环境变量漏配导致的站点验证失败归零。
- **优先级**：**P2**（文档一致性，见 [tasks.md](./tasks.md) O-08），建议 2027-02-01 前完成。

### O-09 域名收敛

- **背景**：已确认 `chroma.appti.cn` 为唯一规范域名；旧域名 `chromacheck.app` / `chroma.ewuse.com` 由 Next 301 收敛，metadata / OG URL 与 sitemap 同步使用 `SITE_URL`。
- **方案**：确认最终域名 → 更新 `lib/site.ts` 的 `SITE_URL` → 配置 301 跳转 → 更新 sitemap / robots / README 与 FAQ 链接。
- **预期效果**：搜索结果中规范域名占比 100%，跨域名重复内容归零。
- **优先级**：**P3**（需业务决策），时间待域名确认。

### 未来展望

中长期方向仍以「隐私优先、本地优先」为基线：在引入账号与云同步前，需要先完成 O-01 / O-02 的安全与合规收口，并由医学顾问验证判读口径；服务端化、开放 API 与 AI 辅助判读均属 v2.0 远景，当前**未实现**，不应写入已落地能力。
