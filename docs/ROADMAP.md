## 2. v1.0 — MVP（当前阶段）

### 2.1 目标

完成核心色觉检测闭环，验证产品可行性。

### 2.2 功能范围

**包含**：
- 首页 / 检测前指引
- 石原氏数字图测试（快速 10 题 / 标准 38 题）
- 判读算法（类型、程度、置信度）
- 结果展示（维度分析 + 解读 + 建议）
- 历史记录（本地存储）
- 响应式 + 深色模式

**不包含**（推迟到后续版本）：
- 路径追踪测试
- 色相排列测试
- 用户账号
- 报告导出（PNG/PDF）

### 2.3 完成标准

- [ ] 完整检测流程可运行
- [ ] 判读算法测试覆盖 ≥ 95%
- [ ] 部署上线
- [ ] 隐私合规检查通过

### 2.4 里程碑

| 阶段 | 内容 | 工期 |
|------|------|------|
| M1 | 项目初始化、首页、指引 | 1 周 |
| M2 | 石原氏测试、判读引擎 | 2 周 |
| M3 | 结果展示、历史记录 | 1 周 |
| M4 | 测试、上线 | 1.5 周 |

## 3. v1.1 — 体验完善

### 3.1 目标

提升检测准确性、易用性和用户留存。

### 3.2 功能清单

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 路径追踪测试 | 区分红/绿色盲类型 |
| P0 | 报告导出（PNG/PDF） | 方便保存分享 |
| P1 | 38 板完整石原氏图谱 | 更全面题库（**v1.5 已实现**） |
| P1 | 检测结果分享卡片 | 社交分享优化 |
| P1 | 趣味性体验包 | 进度点阵仪式感、章末科普过渡、旅人称号、Canvas 分享卡、换一双眼睛、三轴互动科普；红线与开关设计见 SPEC §3.5（**v1.4 已实现**） |
| P1 | 屏幕校准指引 | 降低显示差异影响 |
| P2 | 英文版 | 国际化第一步 |
| P2 | PWA 支持 | 离线可用、安装到桌面 |
| P0 | 驾驶员场景专项检测与合规映射 | 结果页「驾照辨色力参考」栏 + 信号灯辨识任务（详见 `docs/TASKS.md`） |
| P1 | 红绿色弱与色盲语义澄清 | 结果文案区分 dichromacy/anomalous 并对照 172 号令（详见 `docs/TASKS.md`） |

### 3.3 成功指标

- 检测完成率 > 75%（趣味性体验包上线后对照组再提升）
- 报告导出率 > 15%；分享卡生成率 > 8%
- 移动端访问占比 > 60%

## 4. v1.5 — 用户体系

### 4.1 目标

建立用户体系，实现数据云同步，覆盖更多场景。

### 4.2 功能清单

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 用户账号系统 | 邮箱 / 微信 / 手机号登录 |
| P0 | 历史记录云同步 | 跨设备查看 |
| P1 | 儿童模式 | 图形识别替代数字，适合 5-10 岁 |
| P1 | 色觉模拟器 | 正常色觉者体验色盲视角 |
| P1 | 批量检测管理后台 | 学校 / 企业使用 |
| P2 | 家庭共享 | 家庭成员结果共享 |

### 4.3 技术需求

- 引入数据库（PostgreSQL / Supabase）
- 引入认证（Auth.js / NextAuth）
- 数据加密与合规升级

## 5. v2.0 — 平台化

### 5.1 目标

成为专业色觉检测平台，探索 B 端和医疗合作。

### 5.2 功能清单

| 方向 | 功能 | 说明 |
|------|------|------|
| AI 能力 | AI 辅助判读 | 结合历史数据优化准确性 |
| 硬件 | 摄像头环境光校准 | 手机端更准检测 |
| 医疗 | 眼科医院合作 | 在线预约转诊 |
| B 端 | 企业 API | 第三方集成色觉检测 |
| B 端 | 体检机构对接 | 批量检测 + 报告导出 |
| 科研 | 匿名数据研究 | 色觉流行病学研究（需伦理审批） |

### 5.3 商业探索

- B 端 API 付费
- 医疗机构合作分成
- 企业筛查服务
- 专业报告增值服务
