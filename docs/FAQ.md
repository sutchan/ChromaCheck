## 1. 检测与结果

### Q1：ChromaCheck 能准确判断我是不是色盲吗？

不能作为诊断依据。工具基于石原氏检测原理做**规则化初筛**，受屏幕、环境光与作答状态影响。题库只有演示题、常规数字题与消失型题，没有转换型 / 隐藏型题，因此**不能可靠区分红 / 绿 / 蓝黄异常类型，也不能区分「色盲」与「色弱」**。结果异常请到正规医院眼科用专业仪器确诊。

### Q2：为什么结果里的「异常类型」显示为空？

无轴命中时判读输出 `type = null`（未分型，v1.15.1 起不再默认输出「绿色弱 / 盲」）。这既不表示确诊异常，也不表示完全正常，只是当前题型无法给出类型结论。三轴中的 tritan 为 `base × 0.35` 推算参考值。

### Q3：快速检测和标准检测有什么区别？

石原氏快速为 10 题、标准为 38 题；题量越大，统计稳定性越好。其他范式也有各自的 quick / standard 模式。赶时间可用快速版了解大致情况，需要更完整参考请用标准版。

### Q4：路径追踪的分数是怎么算的？

用 F1 分数衡量你描的线与预设路径的重合度（**不是 IoU，也不是简单的命中比例**），通过阈值 `PASS = 70`、`TOL = 0.07` 判定。得分低可能只是线条偏移，不等于色觉结论。

### Q5：色相排列 D15 的「偏差方向」为什么只有两种？

D15 判读只输出 `deutan` / `tritan` / `none`，不输出 `protan`。这是当前判读实现的口径，不代表不存在红色觉异常。

### Q6：儿童图形检测的结果代表什么？

按错题数分三档：错 0 题 `normal`、错 1–2 题 `suspected_deficiency`、错 ≥3 题 `suspected_blindness`。仅为筛查提示，不是医学结论。

## 2. 数据与隐私

### Q7：需要注册或登录吗？

不需要。应用没有账号体系，无登录、无注册、无角色权限控制，打开即用。

### Q8：我的检测结果存在哪里？

全部存在当前浏览器的 `localStorage`：结果 `cc.results.v1`、设置 `cc.settings.v1`、进度 `cc.progress.v1`、档案 `cc.profiles.v1` / `cc.activeProfile.v1`、批量名单 `cc.batch.v1`、语言 `cc.lang.v1`。**没有服务端数据库，没有云端或 Blob 存储**。

### Q9：数据会上传吗？

答题记录与判读结果不会上传。站点仅通过 Google Analytics 采集匿名页面访问（`page_view`），不含检测结果。配置 `NEXT_PUBLIC_GA_ID` 为空即可停用统计。详见 [PRIVACY.md](./PRIVACY.md)。

### Q10：换设备或清除浏览器数据后历史还在吗？

不在。数据只在当前浏览器，清除站点数据会一并清除。请用历史页的「导出 JSON」备份，再在新设备「导入 JSON」恢复。历史最多保留 30 条。

### Q11：能删除某条结果或档案吗？

可以在历史页删除单条结果；档案可删除自建档案，**默认档案不可删除**（`lib/profile.ts` L103–104）。

## 3. 功能与使用

### Q12：答题中途退出会丢失进度吗？

不会完全丢失。草稿写入 `cc.progress.v1`，再次进入同一范式可断点续测；草稿写入失败会静默降级，结果写入失败则在历史页提示，极端情况下仍可能丢失，重要检测建议一次完成。

### Q13：怎么导出报告？

结果页 / 历史页提供四种方式：PNG（Canvas 生成报告图或分享卡）、打印 PDF（`window.print()` 另存）、复制文字、导出 JSON。全部在浏览器本地完成，不产生上传请求。

### Q14：五种色觉视角是什么？

结果页可切换五种色觉视角查看同一结果，首页模拟器提供四种视角，用于观察不同色觉类型的显示差异；视角图仅作演示，不参与判读。

### Q15：驾驶场景模式有什么用？

通过 `scene=driver` 参数进入，给出与驾驶体检相关的合规提示。法规只禁「红绿色盲」，未明确「色弱」，各地体检尺度不一；本工具不能作为驾考体检结论。

## 4. 语言、设备与无障碍

### Q16：支持哪些语言？

界面文案三语：简体中文（默认）→ 繁體中文 → English，偏好写入 `cc.lang.v1`。科普文章、隐私政策等**内容型长文本只有简中 / 英文**，繁体环境回退简体；页面 metadata 与 JSON-LD 恒为简体（SEO 优先）。

### Q17：支持键盘操作吗？

支持。石原氏可用数字键追加、`Backspace` 删除、`Enter` 提交；手风琴等控件带 `aria-expanded` / `aria-controls`，页面提供跳转到主内容链接，并尊重 `prefers-reduced-motion`。

### Q18：能离线使用吗？

注册为 PWA 后可添加到主屏幕；断网时进入 `/offline` 兜底页。检测逻辑本身在浏览器内，但离线缓存覆盖范围有限，建议在线完成关键检测。

### Q19：页面显示异常或检测跑不起来怎么办？

见 [TROUBLESHOOTING.md](./TROUBLESHOOTING.md)；仍无法解决请在 [GitHub Issues](https://github.com/sutchan/ChromaCheck/issues) 反馈，附浏览器版本、操作系统与复现步骤。
