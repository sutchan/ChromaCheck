# 2026-11-27 代码审查与鲁棒性修复（v1.17.8）

> `[现行]` 本轮基于实际代码审查修复，全部经门禁实测复核。

## 修复清单

1. **判读口径**
   - `lib/scoring.ts`：错误率改为 `answeredWrong / answered`，未作答题不再当错误；severity 同源修正。注意 `vanishWrong >= 4` 仍是独立判盲规则，测试需用 normal 型题目隔离验证。
   - `lib/path-scoring.ts` / `lib/advanced-scoring.ts`：两轴均无命中返回 `type = null`，与 `scoreIshihara` 和 SPEC §6.4 一致；`pathF1` 对空标准路径返回 0 而不是 NaN。

2. **数据安全**
   - `lib/export-import.ts`：`parseImport` 改为逐字段白名单校验（`schema` 固定 `history-bundle/v1`、档案/结果元素非 null、拒绝 `__proto__` / `constructor` / `prototype`），阻断合并阶段 TypeError 与原型污染。
   - `csvCell`：对 `= + - @ \\t \\r` 前缀加单引号，防止 Excel / Sheets 公式注入。

3. **路由与场景链路**
   - Next.js 16 的 `searchParams` 是 Promise，服务端页必须 `await` 再读；`app/test/advanced/page.tsx` 原同步访问导致 `?scene=driver` 恒失效。
   - `scene=driver` 链路：`GuideContent` CTA → `app/test/page.tsx` → `TestSelectContent`（模式链接追加 `?scene=driver`）→ `app/test/ishihara/[mode]/page.tsx` → `TestRunner` → `computeResult.scene`。进阶页同样 await。

4. **React 稳定性**
   - `IshiharaPlate` 动画帧、`SignalRunner` / `ReportActions` 定时器补卸载清理。
   - `HomeFaq` FAQPage JSON-LD 恒定简体（`translate('zh', key)`），不随界面语言切换（SPEC §8.7）；React key 不再使用译文。

5. **语义化 id**
   - 页面壳 `*-page` 与内容组件 `*-content` 去重：guide / privacy / offline。
   - 新增：首页模拟器 / 事实块 / 特性 / 流程、指引步骤与校准网格、`guide-driver-cta`、驾驶模式卡片、原型四页主要容器。
