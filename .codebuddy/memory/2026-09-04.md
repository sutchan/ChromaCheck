# 2026-09-04

## ChromaCheck 高保真原型搭建（v0.1.0 起点）
- 在 `prototype/` 下从零搭建纯静态原型集（无构建依赖），三页互相链接：
  - `prototype.html`：高保真可交互产品原型（设备画框切换 + 色觉模拟 + 真实题库/判读数据）
  - `wireframes.html`：组件库规范（基础/复合/业务组件 + 使用规则 + 无障碍基线）
  - `design-system.html`：设计系统（色彩/字体/间距/圆角/阴影令牌 + 色觉模拟基线）
- 样式分层：`tokens.css`（设计令牌）/ `ui.css`（基础组件）/ `screens.css` / `screens-test.css`（业务屏）/ `docs.css`（规范页外壳）
- 逻辑分层：`data.js`（真实题库）/ `scoring.js` / `ishihara.js`（`CC.renderPlate`/`renderPathField`/`simulate`）/ `charts.js` / `screens-*.js`（屏幕渲染）/ `wireframes.js`（组件目录渲染+轻量 toast/modal）/ `design-system.js`（自包含色觉模拟矩阵）
- 组件目录数据：`wireframes-catalog-base.js` / `-comp.js` / `-biz.js` 各自 push 到 `window.CC_CATALOG`
- `prototype.html` 外壳已加入跳转到 wireframes/design-system 的入口
- 注：ChromaCheck 仓库当前无 `package.json` / `VERSION` 单一版本源，原型文件头统一 v0.1.0
- README 已补充「高保真原型」章节（入口 + 目录结构）
