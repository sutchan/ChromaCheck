> **时效标注**：本文是 2026-11-05 当时的审查快照，已于 2026-11-22 逐条校正。第 3、5 节的原文结论已失效，以下为校正后口径；现行规范以 `docs/SPEC.md` 为准。

### 1. JSON-LD 注入已做安全转义 `[现行]`
`components/seo/JsonLd.tsx` 的 `safeJson()` 将 `<` `>` `&` 与 U+2028 / U+2029 转义（v1.17.0 修复历史 no-op）；纵深防御脚本断点注入，即便数据来自可信常量也勿移除。

### 2. 语义 id 覆盖 `[现行]`
- 主要页面与组件关键容器均已带 kebab-case 语义 id（`main-content` / `result-page` / `guide-page` / `app-footer` 等）。
- 原型 `prototype/*.html` 已有 47+ 语义 id；`prototype/assets/js/*.js` 超 200 行文件豁免拆分（设计参考、经典全局脚本）。

### 3. 判读阈值 `[已校正 — 原结论失效]`
原文写「`wrongRate = wrong/total`、非绝对计数、97 例」，**已失效**。现行口径见 `docs/SPEC.md` §6.3 与 `lib/scoring.ts`：`wrongRate = wrong / Math.max(answered, 1)`，并保留 `vanishWrong >= 4` / `>= 2` 混合阈值；程度用 `rate = wrong / Math.max(total, 1)`。当前测试基线为 16 文件 111 例（2026-11-27 / v1.17.4）。

### 4. 测试环境限制 `[现行]`
Vitest 跑在 node 环境（`vitest.setup.ts` 注入内存 Storage，无 jsdom/happy-dom），`report-canvas.ts` / `sharecard-canvas.ts` 的 Canvas 绘制不可单测（仅 `sharecard.ts` 的 `computeRadar` 覆盖）；勿强行加 jsdom。

### 5. 版本、lockfile 与构建 `[已校正 — 原结论失效]`
原文写「版本 1.13.2、页脚小写 `v{ver} · build`、CI 不提交 lockfile、`SITE_UPDATED` 仅用于隐私页」**均已失效**。现行：
- 版本单一来源为 `VERSION` / `package.json` / `package-lock.json`（当前 v1.17.0，实查为准）；
- 页脚格式 `V{ver}· build {10位yymmddhhmm}`，只在页脚（`docs/SPEC.md` §3.6）；
- `package-lock.json` 自 v1.11.2 起已提交；`ci.yml` 用 `npm install` 且**不配 `cache`**；
- `SITE_UPDATED` 还用于 sitemap `lastModified`、`llms*.txt`、科普 Article 日期与隐私页（`docs/SPEC.md` §8.7）；
- 本地 `next build` 可能被 IDE safe-delete 护栏拦截，CI 不受影响。
