# 2026-09-07

## 修复 ChromaCheck 全部已审查 bug（v1.7.2 → v1.7.3）

用户要求「修复所有」。改动文件：`useIshiharaFlow.ts`、`TestRunner.tsx`、`AdvancedRunner.tsx`、4 个测试子页、`sitemap.ts`、`loading.tsx`（新）、`VERSION`/`package.json`/`README.md`/`CHANGELOG.md`。

修复内容：
- **演示题作末题卡死**：`advanceFromReveal` 原 `setIdx(idx+1<total?idx+1:idx)`，若演示题为末题则无操作、永不完成；改为 `idx+1>=total` 时直接 `onDone(answers)`。
- **「恢复进度」功能整体失效（关键隐患）**：`TestRunner`/`AdvancedRunner` 通过 `useEffect` 异步写 `initial`，而 `useIshiharaFlow` 的 `useState(initial?.index ?? 0)` 仅首挂载生效 → 恢复总是从第 1 题开始。改用**挂载门控**（`mounted` state，effect 内 `setMounted(true)` 且先 `setInitial`），`IshiharaFlow` 仅在 `mounted` 后挂载，首挂载即带正确 `initial`；SSR/水合阶段 `mounted=false` 渲染占位，避免水合不匹配。
- **进阶模式石原氏进度丢失**：进阶 `IshiharaFlow` 现接 `initial`+`onProgress`（持久化 `mode:'advanced'`），`onIshiharaDone`/`restart` 调 `clearProgress()`；刷新中途可恢复石原氏阶段。
- **SEO/站点结构**：4 个测试页补 `generateMetadata`（标题/描述/canonical/OG）；色相排列/路径追踪补 `generateStaticParams`；`sitemap.ts` 补全 `/test/ishihara/{quick,standard}`、`/test/advanced`、`/test/hue-arrangement/standard`、`/test/path-tracking/standard`；新增 `app/loading.tsx`。

验证：`tsc --noEmit` 通过；`next lint` 仅余 `layout.tsx` 自定义字体既有告警（无关）；`next build` 成功，25 页全量生成（hue/path/ishihara 已 SSG 预渲染 quick/standard，advanced 动态）。

注意：`CODEBUDDY_SAFE_DELETE_ENABLED=0` 可绕过构建清理阶段的 safe-delete shim 超时（仍有效）。
